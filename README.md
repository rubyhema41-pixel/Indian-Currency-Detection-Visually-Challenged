# Indian Currency Detection for Visually Challenged Using Deep Learning

## Overview
This project is an AI-based system that helps visually impaired individuals identify Indian currency notes and detect counterfeit notes using Deep Learning.

## Features
- Detects fake and genuine currency.
- Identifies the denomination (₹10, ₹20, ₹50, ₹100, ₹200, ₹500, ₹2000).
- Announces the detected value using voice output.
- Real-time webcam support.
- Image upload option.

## Technologies Used
- Python
- TensorFlow/Keras
- YOLOv8
- OpenCV
- NumPy
- gTTS
- Tkinter

## Models
- MobileNet – Fake/Genuine Currency Detection
- YOLOv8 – Currency Denomination Detection

## Dataset
The project uses publicly available Indian currency datasets from Kaggle.
